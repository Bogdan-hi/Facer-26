# 📸 Facer-26

> Интеллектуальная система автоматической проверки фотографии лица пользователя при регистрации.

Проект реализует:
- захват фотографии через веб-интерфейс;
- предварительную подготовку изображения;
- каскадную валидацию фотографии;
- проверку качества лица;
- детекцию маски;
- детекцию солнцезащитных очков;
- realtime-подготовку кадра перед съёмкой.

---

## 📋 Основные возможности

Система автоматически определяет:

- ✅ наличие лица;
- 🔢 количество лиц в кадре;
- 💡 качество освещения;
- 🔄 наклон головы;
- 🌫️ размытость изображения;
- 🚫 перекрытие лица;
- 😷 наличие медицинской маски;
- 🕶️ наличие солнцезащитных очков.

## 🔍 Логика работы системы

### 1. Загрузка фотографии
Пользователь:
- загружает фотографию с диска;
- **или** делает снимок через webcam-интерфейс.

### 2. Проверка количества лиц
**MediaPipe Face Detector** определяет количество лиц.  
**Требование:** в кадре должен присутствовать строго **один человек**.

### 3. Проверка положения головы
Вычисляется угол наклона головы по ключевым точкам глаз.  
Если угол превышает допустимое значение – фотография **отклоняется**.

### 4. Проверка освещения
Анализируется средняя яркость изображения.  
Проверяются:
- слишком тёмные изображения;
- пересвеченные изображения.

### 5. Проверка качества изображения
Используется **Laplacian Variance**:
- определяется размытость;
- оценивается резкость лица.

### 6. Проверка перекрытия лица
Система определяет:
- частичное перекрытие лица;
- сильную размытость;
- потерю ключевых деталей.

### 7. Детекция маски
**YOLOv8 модель:** `mask_detection.pt`  
Классы:
- `0` = face
- `1` = face_mask

Если обнаружена маска – фотография **отклоняется**.

### 8. Детекция солнцезащитных очков
**YOLOv8 модель:** `sunglasses_detection.pt`  
Классы:
- `0` = sunglasses

Если очки обнаружены – фотография **отклоняется**.

## 📸 Realtime-подготовка фотографии

Модуль **`camera_capture.py`** отвечает за сегментацию лица в реальном времени и подготовку кадра для дальнейших проверок.

### 🧠 Загружаемые модели (`.tflite`)

- **`selfie_segmenter.tflite`** – сегментация человека и фона. Создаёт маску: человек / фон. Используется для размытия фона и фокусировки на лице.
- **`blaze_face_short_range.tflite`** – лёгкий детектор лиц BlazeFace. Оптимизирован для фронтальной камеры, ближних дистанций, realtime-работы. Возвращает bounding box лица.

### 🔄 Пошаговая логика работы

1. **Инициализация** – создаются объекты `ImageSegmenter` и `FaceDetector` в режиме `VIDEO` (поддержка последовательных кадров и синхронизации по timestamp).
2. **Захват кадра** – кадр считывается с webcam и зеркально отражается (flip) для естественного взаимодействия.
3. **Сегментация человека** – маска преобразуется в бинарную (порог > 0.1), при необходимости масштабируется.
4. **Размытие фона** – определяется передний/задний план; маска сглаживается `GaussianBlur` и усиливается контраст; фон размывается сильным гауссовым фильтром (35×35). Финальный кадр: `output = frame * mask_f + blurred * (1 - mask_f)`.
5. **Целевой квадрат (ROI)** – в центре экрана отображается квадрат (50% от меньшей стороны кадра) для позиционирования лица. Цвет меняется: красный – плохое положение, зелёный – правильное.
6. **Детекция лица** – получается bounding box, оцениваются позиция и размер лица относительно целевого квадрата. Финальный score: `score = pos_score * size_score`, применяется экспоненциальное сглаживание `score_smooth = 0.8 * previous + 0.2 * current`.
7. **Плавное затемнение** – если лицо плохо выровнено, экран затемняется полупрозрачным чёрным слоем.
8. **Интерфейс и съёмка**:
   - 🔴 `Align the face with the area`
   - 🟢 `Perfect - press SPACE`
   - По нажатию **SPACE** (при корректном положении лица) сохраняется `captured_face.jpg`.
   - **ESC** закрывает приложение.
9. **Таймкод** – на каждом кадре увеличивается `timestamp` для синхронизации MediaPipe.

## 🌐 Веб-интерфейс

Интерфейс предоставляет:
- загрузку изображения;
- предпросмотр фотографии;
- webcam-съёмку;
- отображение результата проверки;
- цветовую индикацию статуса.

### 🟢🛑 Цветовая индикация
- **Зеленый** – фотография успешно прошла проверку.
- **Красный** – фотография отклонена, отображается причина отказа.

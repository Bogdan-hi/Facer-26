# Facer-26

Интеллектуальная система автоматической проверки фотографии лица пользователя при регистрации.

Проект реализует:
- захват фотографии через веб-интерфейс;
- предварительную подготовку изображения;
- каскадную валидацию фотографии;
- проверку качества лица;
- детекцию медицинской маски;
- детекцию солнцезащитных очков;
- realtime-подготовку кадра перед съёмкой.

---

# Основные возможности

## Проверка фотографии пользователя

Система автоматически определяет:

- наличие лица;
- количество лиц в кадре;
- качество освещения;
- наклон головы;
- размытость изображения;
- перекрытие лица;
- наличие медицинской маски;
- наличие солнцезащитных очков.

Логика работы системы
1. Загрузка фотографии

Пользователь:

загружает фотографию;
или
делает снимок через webcam-интерфейс.
2. Проверка количества лиц

MediaPipe Face Detector определяет количество лиц.

Требование:

в кадре должен присутствовать строго один человек.
3. Проверка положения головы

Вычисляется угол наклона головы по ключевым точкам глаз.

Если угол превышает допустимое значение:

фотография отклоняется.
4. Проверка освещения

Анализируется средняя яркость изображения.

Проверяются:

слишком тёмные изображения;
пересвеченные изображения.
5. Проверка качества изображения

Используется Laplacian Variance:

определяется размытость;
оценивается резкость лица.
6. Проверка перекрытия лица

Система определяет:

частичное перекрытие лица;
сильную размытость;
потерю ключевых деталей.
7. Детекция медицинской маски

YOLOv8 модель:

mask_detection.pt

Классы:

0 = face
1 = face_mask

Если обнаружена маска:

фотография отклоняется.
8. Детекция солнцезащитных очков

YOLOv8 модель:

sunglasses_detection.pt

Классы:

0 = sunglasses

Если очки обнаружены:

фотография отклоняется.
Realtime-подготовка фотографии
segmentation.py

segmentation.py - сегментация лица пользователя в реальном времени, подготовка фотографии лица пользователя для дальнейших проверок.

Загружаемые модели (.tflite)
selfie_segmenter.tflite

Модель для выделения человека из фона (сегментация).

Создаёт маску:

человек;
фон.

Используется для:

размытия фона;
фокусировки внимания на лице пользователя.
blaze_face_short_range.tflite

Лёгкий детектор лиц BlazeFace.

Оптимизирован:

для фронтальной камеры;
ближних дистанций;
realtime-работы.

Возвращает:

bounding box лица.
Пошаговая логика работы realtime-сегментации
1. Инициализация

Создаются объекты:

ImageSegmenter
FaceDetector

Используется режим:

VIDEO

Он поддерживает:

последовательные кадры;
временную синхронизацию через timestamp.
2. Захват кадра

Кадр:

считывается с webcam;
зеркально отражается (flip).

Это делает взаимодействие более естественным для пользователя.

3. Сегментация человека

Маска из модели преобразуется в:

mask

Диапазон:

0..1

Если размер маски отличается:

выполняется resize.

Создаётся бинарная маска:

condition = mask > 0.1
4. Размытие фона

Автоматически определяется:

что является foreground;
что является background.

Если среднее значение маски > 0.5:

выполняется инверсия.
Сглаживание маски

Применяется:

GaussianBlur

Дополнительно:

усиливается контраст маски.
Размытие background

Используется сильное Gaussian Blur:

35×35

Финальный результат:

output = frame * mask_f + blurred * (1 - mask_f)
5. Целевой квадрат (ROI)

В центре экрана отображается квадрат.

Назначение:

правильное позиционирование лица.

Размер:

50% от меньшей стороны кадра.
Цветовая индикация

Цвет изменяется:

красный → плохое положение;
зелёный → правильное положение.
6. Детекция лица

Получается:

bounding box
Вычисление score

Оцениваются:

Позиция лица

Отклонение:

по X;
по Y.
Размер лица

Сравнивается:

размер bounding box;
целевой размер квадрата.
Финальный score
score = pos_score * size_score
Экспоненциальное сглаживание
score_smooth =
    0.8 * previous +
    0.2 * current
7. Плавное затемнение

Если лицо плохо выровнено:

экран затемняется.

Используется:

addWeighted

Накладывается:

полупрозрачный чёрный слой.
8. Интерфейс и съёмка
Сообщения интерфейса
Красное сообщение
Align the face with the area
Зелёное сообщение
Perfect - press SPACE
Сохранение фотографии

Если:

нажата SPACE;
лицо корректно выровнено;

то:

captured_face.jpg

сохраняется на диск.

ESC

Закрывает приложение.

9. Таймкод

На каждом кадре:

timestamp += 1

Это необходимо:

для синхронизации MediaPipe;
корректной работы VIDEO режима.
Веб-интерфейс

Интерфейс предоставляет:

загрузку изображения;
предпросмотр фотографии;
webcam-съёмку;
отображение результата проверки;
цветовую индикацию статуса.
Цветовая индикация
Зеленый

Фотография успешно прошла проверку.

Красный

Фотография отклонена.

Пользователю отображается причина отказа.
